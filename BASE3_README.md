# Base 3 quick test

1. Open the Grimoire (`R`).
2. Click **Script Builder**.
3. Click **Base 3** in the upper-right.
4. Choose Trouble Brewing, Bad Moon Rising, or Sects & Violets.
5. Return to the Grimoire and confirm the script name changed.
6. Open **Role Bag** and confirm the full role list is available.

The three scripts are bundled resources and are not mixed into custom-script
storage or the custom Script Builder selection.
