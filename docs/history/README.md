# Historical Development Notes

This directory contains documentation retained from the staged Blood on the Sharktower port.

These files are **historical records**, not current installation instructions.

## Folders

- `a11/` — A.11 implementation notes, hotfix descriptions and regression notes.
- `port-notes/` — staged port milestone notes from 0.x through the 1.1.0 development milestones.
- `patch-instructions/` — old APPLY/INSTALL/hotfix patch instructions used before the repository became the source of truth.
- `feature-notes/` — older standalone feature notes such as Role Bag, hand voting and private-chat documentation.
- `migration/` — baseline and Minecraft 26.3 migration notes.

- `../../README.md`
- `../PORT_STATUS.md`
- `../../A12_RELEASE_CANDIDATE_CHECKLIST.md`
