# A.11 — Vortox Night Visit Warning

Adds a Storyteller-only Vortox warning to the existing Night Visit information card.

When a true Vortox is present in the Storyteller's authoritative Grimoire, every
night-visit card gains one extra line immediately below the Droisoned status:

`Vortox: YES`

The line is red and is omitted entirely when no Vortox is in play. It does not
change the calculated "true" information shown above it; it is a fast reminder
to the Storyteller that Vortox makes Townsfolk information false.

No additional hidden information is sent to player clients; the check uses the
Storyteller's existing Grimoire state locally.
