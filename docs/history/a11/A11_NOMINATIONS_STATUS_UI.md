# A.11 — Nominations status UI patch

Changes the passive `NOMINATIONS OPEN` state from the large top-centre election panel to a compact green status line above the hotbar.

- The Storyteller phase/night-order bar remains readable at the top of the screen.
- The full election panel still appears for an actual nomination, vote, exile, player on the block, or vote result.
- The green status line is positioned above the existing hand-vote helper so the two do not overlap on player clients.

Apply this patch over the current A.11 dev project by copying the contents into the project root and replacing matching files.
