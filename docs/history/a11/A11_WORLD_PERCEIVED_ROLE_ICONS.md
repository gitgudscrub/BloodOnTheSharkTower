# A.11 — World Perceived Role Icons

For Storyteller clients, players with a configured perceived role now show two
floating role tokens above their head:

- left: true role (e.g. Drunk / Marionette)
- right: believed role (e.g. Chef / Empath)

The pair is camera-relative, so it stays visually side-by-side as the
Storyteller moves around.

Ordinary players are unchanged. Their Grimoire sync never includes the
perceived-role map, so this does not leak Drunk/Marionette information.

At final reveal, non-Storyteller clients continue to see only the true revealed
role.
