# Private BOTB 26.2 Baseline

Candidate: Blood on the Sharktower 0.8.2

This project is a private derivative/port of Blood on the Blocktower, used with permission for private use only. Do not publicly distribute source, assets, or compiled builds without further permission.

Baseline scope:
- Minecraft 26.2 / Fabric / Java 25 project shell
- BOTB role and script models
- server/client state synchronization
- seating, role assignment, Storyteller setup, reminders and bluffs
- nominations, voting, executions, exiles and timers
- seat-home / town-square teleport controls
- BOTB-style circular Grimoire and primary Storyteller UI
- real connected-player names/heads with synthetic test-player fallbacks

After visual verification, branch future work from this baseline and add Blood on the Sharktower features intentionally.
