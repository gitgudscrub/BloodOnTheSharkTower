# 1.0.2 session feedback patch

Status: development build `1.0.2-alpha.1`; community live testing remains on 1.0.1.
Based on main after PR #6 (Modrinth release pipeline) merged.

## Behaviour

- Connection refreshes run at `END_SERVER_TICK`, rather than `server.execute`, which can execute inline during JOIN/DISCONNECT. New clients receive a complete refresh; existing clients receive updated seats, Grimoire and player directory. Setup disconnects release/compact seats; active-game reconnects keep their seat.
- Grimoire RMB and Shift+RMB use `SDLMouse.SDL_BUTTON_RIGHT` (3). SDL's middle button is 2. Coordinate remapping for GUI scales above 4 is retained.
- Storyteller role borders read the current authoritative Grimoire assignment, including Force Good/Force Evil and custom roles. Unassigned seats are neutral.
- Ordinary player role borders read only their personal Good/Evil reminders. Role defaults, other players' actual assignments, public Traveller roles and Spy/Widow snapshots never set a personal border.
- Adding Good or Evil replaces either existing personal alignment reminder. Removing that reminder, Clear Read, or Clear All Reminders makes the border neutral. Read Good/Read Evil use the same reminder state and work on blank role slots too.
- Role guesses and ability snapshots do not overwrite personal alignment reads. Personal notes never send a packet or change Storyteller state. Leaving a server clears the client notebook.
- Final Grimoire reveal retains its existing public final-alignment presentation.

## Multiplayer regression checklist

Code verification: 21 alignment-note and 13 connection-lifecycle checks passed against the actual edited classes using isolated game API stubs. These checks cover note exclusivity/removal, authoritative versus personal reads, ability snapshots, custom-role alignment, delayed joins/disconnects, same-tick reconnects and server-stop cleanup. The Java 25 client/server Gradle build also passed in GitHub Actions. In-game input, appearance and real multiplayer behaviour still require the checks below.

Use the core harness first, then the extended harness for vote shortcuts.

1. Keep the Storyteller Grimoire/sidebar open while players connect one at a time. Every client must immediately show the newest player's name, head and seat without manually reopening or refreshing.
2. Disconnect a middle setup seat; verify seats compact and the sidebar updates. Reconnect. During a running game, disconnect/reconnect and verify the original seat, role and death state return.
3. RMB both a player portrait and role token: open Player Actions. LMB must still edit roles/reminders. Middle-click must not open Player Actions. Repeat at GUI scale 4 and above 4.
4. Open nominations, Shift+LMB a nominator, then Shift+RMB a nominee. Verify the correct pair. With nominations closed, verify the shortcut refuses. Repeat on a believed-role token and with either Shift key.
5. Force a Storyteller's Townsfolk Evil and a Minion Good; verify red/blue borders update while the Grimoire is open. Restore default alignment and repeat on a custom role. Verify dead/exiled and nomination/hover markers remain legible.
6. On a player's own Grimoire, verify every untouched seat is neutral, including their own known role and public Travellers. Add Good, then Evil, then Evil again: exactly one personal alignment reminder remains and the border is red. Remove it: neutral.
7. Repeat on a blank role slot; add unrelated reminders, change the guessed role, and use Read Good/Read Evil/Clear Read. Other reminders survive Clear Read. Clear All Reminders restores neutral.
8. A second player must not see the first player's notes; the Storyteller's assignments/reminders must not change. Force an actual alignment change: it must not overwrite either player's personal read.
9. Share a Spy/Widow Grimoire containing alignment overrides and Good/Evil Storyteller reminders: personal borders must retain their prior reads or remain neutral. Remove a shared reminder and verify it does not clear the personal read; remove the personal alignment reminder and verify neutral.
10. Leave the server and join another session: old personal role/reminder/alignment notes must be cleared. Verify Final Grimoire still reveals final actual alignments at game end.
