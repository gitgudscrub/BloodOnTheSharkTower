# 0.9.0 — Sharktower Role Bag

This is the first post-baseline Blood on the Sharktower feature.

## Role Bag

The Storyteller can now open **Role Bag** from the Grimoire and explicitly
select the exact characters that should be in play. The bag must contain the
same number of characters as seated players. When **Distribute Bag** is used,
the server randomly assigns those selected characters to the seated players.

The assignments remain pending in the Storyteller Grimoire until **SEND ROLES**
is pressed, so the Storyteller can inspect or adjust the result first.

The bag supports official and custom script roles in the four player teams:
Townsfolk, Outsider, Minion and Demon. Travelers, Fabled and Loric characters
are excluded from the bag.

The old **Randomize Roles** workflow remains available as a separate option.
